# 第三方素材与代码致谢 / Third-party notices

## pixelfx（MIT）
特效 2.0（炮塔爆炸、电塔闪电、冰塔冰霜、Boss 倒下）的编排参考了 pixelfx：https://github.com/patch-gg/pixelfx

另外直接使用了 pixelfx 的两个效果烘焙成的贴图（按 MIT 许可使用，保留下方版权声明）：
- `fx/pf_whirl.png`：由 pixelfx `nature/tornado` 改编（换成绿白配色、去掉顶部闪电），风行者「疾风号令」的龙卷风。
- `fx/pf_arrow.png`：pixelfx `projectiles/arrow`（尾羽改成绿白配色），风行者「箭雨」的箭。
- `fx/pf_burn.png`：由 pixelfx `fire/campfire` 改编（去掉木柴、减少烟雾，做成 3 种火团形态），怪物「燃烧」状态的身上火焰。
- `fx/pf_steam.png`：由 pixelfx `explosions/smoke-bomb` 改编（去掉烟雾弹罐子，换成白色水汽、往上冒），合体「蒸汽爆炸」。
- `fx/pf_ember.png`：pixelfx `fire/fire-ring`，合体「余烬」。
- `fx/pf_pshot.png`、`fx/pf_plasma.png`：pixelfx `projectiles/plasma-shot` 与 `explosions/plasma-explosion`（爆炸换成绿色），合体「等离子」。
- `fx/pf_gold.png`：pixelfx `spawn/coin-drop`（烟团换成熔金橙色），合体「熔金」。
- `fx/pf_over.png`：pixelfx `impacts/crit-hit`（换成紫色），电塔符文「过载」。
- `fx/pf_cboom.png`：由 pixelfx `explosions/barrel-explosion` 截取（去掉油桶），炮塔命中爆炸。
- `fx/pf_ccrit.png`：pixelfx `impacts/crit-hit`，炮塔 / 电塔 / 冰塔的暴击。
- `fx/pf_zhit.png`：pixelfx `lightning/zap-hit`（换成紫色），电塔命中。
- `fx/pf_wslash.png`：pixelfx `melee/double-slash`（换成绿色），风之心。
- `fx/pf_lpool.png`：由 pixelfx `nature/toxic-puddle` 改成熔岩配色，火之心。
- `fx/pf_fzA.png`、`fx/pf_fzH.png`、`fx/pf_fzB.png`：由 pixelfx `ice/freeze` 改编（去掉里面的角色，只保留冰晶），冰之心。
- `fx/pf_thor.png`：pixelfx `lightning/lightning-strike`，雷之心。
- `fx/pf_land.png`：pixelfx `impacts/heavy-landing`（换成泥土色），建塔落地。
- `fx/pf_upA.png`：由 pixelfx `ui/level-up` 改编（光柱加宽、去掉文字和白闪），升级。
- `fx/pf_poof.png`：pixelfx `spawn/poof`（截掉开头白光），卖塔。
- `fx/pf_coin.png`：pixelfx `pickups/coin-spin`，全局掉落金币。
- `fx/pf_tHigh.png`、`fx/pf_tWell.png`、`fx/pf_tSwamp.png`：pixelfx `nature/earth-spike`、`arcane/rune-circle`、`nature/acid-splash`（换成泥绿色），放置高地 / 符文井 / 沼泽。
以上几项的画法为本游戏重新实现。
